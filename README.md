# Animated ASCII Footer Study

MeshTurbo Lab 的 educational study，研究滚动揭示、实时 ASCII Canvas 与指针交互。目标公开仓库：`MeshTurboLab/animated-ascii-footer`。

第一个工作室 Lab：全屏 Footer 揭示、实时 ASCII 双手、GSAP ScrollTrigger、Lenis 与鼠标字符簇高亮。

## 当前状态

- 原生 HTML / CSS / JavaScript 原型已完成。
- 下一阶段迁移为 Next.js + TypeScript + `@gsap/react`。
- 迁移时补充移动端录屏、reference、motion map、Live Demo 与版权说明。
- 当前两张手部图片在来源确认或替换前不得推送到公开仓库。

```bash
python3 -m http.server 4173
```
